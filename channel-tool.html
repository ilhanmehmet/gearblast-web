GearBlast Channel Tool

Last updated: 19 November 2026

GearBlast Channel Tool is a private command-line tool that runs on the developer's own computer. It manages one YouTube channel, GearBlast-Block_Puzzle_Zone, owned by the same developer. It is not available to the public and has no other users.

What it does

  • Uploads the channel owner's own videos (private or scheduled).
  • Sets custom thumbnails.
  • Uploads caption files and adds translated titles and descriptions.
  • Reads public video statistics and popular videos to plan new content.

Every upload is reviewed and approved manually by the channel owner before it runs. The tool uses the YouTube API Services.

Privacy Policy

By using GearBlast Channel Tool you agree to be bound by the YouTube Terms of Service. The tool uses YouTube API Services; see the Google Privacy Policy.

Data accessed

With the channel owner's OAuth consent, the tool accesses that channel's videos, thumbnails, captions, titles, descriptions and statistics, and public YouTube data such as popular videos and search results.

Use, storage and sharing

  • Data is used only to manage the owner's channel and plan its content.
  • The OAuth token is stored only on the owner's computer. No YouTube data is stored on any server.
  • No data is sold or shared with third parties. The tool sets no cookies and collects no data from viewers.

Revoking access

Access can be revoked at any time from the Google security settings page. Deleting the local token removes all stored credentials.
